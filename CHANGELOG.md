# Changelog

## 3.1.0

Исправления по результатам аудита. Публичный API (props, имена экспортов,
значения `data-mode` / `data-focus`, css-классы `main-dialog`, `ass-dialog`,
`m-header`, `m-body`, `m-footer`, `btn-close-modal`) не изменился.

### Исправлено

- **React больше не попадает в бандл.** `react`, `react-dom`, `react-dom/client`
  и `react-icons` вынесены в `external`. Ранее в `dist` лежала вторая копия
  React/ReactDOM (~1.65 МБ), из-за чего любой контент диалога, использующий
  хуки, падал с `Invalid hook call` (а сам диалог не рендерился).
  Бандл: ~1.65 МБ → ~10 КБ.
- **Ошибка в контенте диалога больше не «вешает» промис.** Добавлен
  error boundary: промис реджектится, контейнер удаляется.
- **`onClose` действительно вызывается** (раньше обработчик назначался в
  несуществующее событие `onclose` у `div`).
- **Диалог закрывается ровно один раз**: повторные вызовы (например `timeOut`
  после ручного закрытия) не резолвят промис повторно и не размонтируют
  React root дважды. Таймер `timeOut` очищается.
- **`componentWillUnmount`**: контейнер удаляется только если он действительно
  в DOM, восстановление фокуса обёрнуто в проверки. Раньше падало при
  использовании `ModalDialog` без `WrapperModal`.
- **Побочные эффекты убраны из конструктора** (`hostDialog` — только без
  самоссылки при повторном конструкторе, `document.activeElement` читается в
  `componentDidMount`).
- **Регистрация `BaseBodyDialog` больше не использует `setTimeout(1)`** —
  `validate` / `getData` / `selfClose` привязываются синхронно к своему
  диалогу (раньше возможна привязка к позже открытому диалогу).
- **Ловушка фокуса** пересчитывает фокусируемые элементы на каждое нажатие Tab
  (динамически добавленные кнопки учитываются) и не даёт фокусу уйти за пределы
  диалога.
- **`findHighestZIndex`** игнорирует `z-index: auto` и имеет осмысленный
  fallback вместо `Number.MIN_SAFE_INTEGER`.
- **CSS**: `.ass-dialog` и `.main-dialog` переведены с `position: absolute` на
  `position: fixed` (оверлей и диалог больше не «уезжают» при прокрутке).
  Удалён неиспользуемый класс `.icon-close` с невалидным свойством `size`.
- **`WrapperModal` больше не мутирует объект props, переданный вызывающим**;
  `__actionUnmount` идемпотентен.

### Изменено

- `peerDependencies`: `react` / `react-dom` — `^18.3.0 || ^19.0.0` (раньше
  только `^19.0.0`, из-за чего пакет нельзя было поставить в проекты на React 18).
- Публичный экспорт типа `ResolvePromise` (тип результата промиса).
- `uuid` заменён внутренним генератором id — минус runtime-зависимость и
  известная уязвимость `uuid@9`.
- `react-icons` перенесён в `dependencies` (используется в рантайме, раньше был
  в devDependencies).
- Добавлены `exports` и `sideEffects`; `./dist/index.css` и `./dist/*` оставлены
  доступными (их использует `audio_map_80/client`).
- `dist/` остаётся в git: пакет раздаётся и как
  `github:ionson100/bsr-modaldialog` (как остальные bsr-* библиотеки), где
  потребителю не нужен шаг сборки и install-скрипты. В `dist` больше нет React
  (34 КБ вместо 3.3 МБ), устаревшие `dist/*/modal/*.d.ts` удалены, CI проверяет
  соответствие закоммиченного `dist` сборке.
- Сборка кросс-платформенная (`node scripts/copy-css.mjs` вместо
  `@powershell copy`), добавлена минификация (terser) и шаг `tsc` для типов.
- Удалён `react-scripts` и ~1400 неиспользуемых транзитивных пакетов:
  `npm audit` — 80 уязвимостей → 7 (остальные — в dev-инструментарии rollup/eslint).
- Добавлены тесты (`node --test`), линтер `typescript-eslint`, `LICENSE`.
